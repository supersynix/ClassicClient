# Classic Client

Fabric client mod for Minecraft 1.21.11.

- Freelook: Left Alt (tap to toggle, or hold; see settings)
- HUD panel: FPS, ping, coordinates, facing, health, armor, clock
- Heart indicator: health of the player/mob under your crosshair
- Settings screen: Right Shift in game

Requires Fabric Loader 0.18+ and Fabric API.
